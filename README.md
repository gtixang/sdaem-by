# 🏠 Sdaem.by — сервис посуточной аренды
**Демо:** [sdaem-by-one.vercel.app](https://sdaem-by-one.vercel.app/)

##  Реализовано

- Главная страница с поисковым фильтром, галереей объявлений, блоками аренды, презентации и информации о сервисе.
- Каталог четырёх категорий: квартиры, коттеджи/усадьбы, бани и сауны, автомобили напрокат.
- Фильтрация по городу, району, станции метро, типу объекта, количеству комнат, диапазону цены и вместимости.
- Дополнительные параметры фильтра, рекомендованные варианты и сброс фильтров.
- Сортировка объявлений по цене: по возрастанию, по убыванию и по умолчанию.
- Переключение плиточного и списочного вида, подсчёт найденных объявлений, пагинация и состояние «ничего не найдено».
- Карточки объектов с изображением, ценой в BYN за сутки, характеристиками, адресом, описанием и контактами владельца.
- Раскрытие контактов владельца (телефон, Viber, WhatsApp, email) с закрытием по клику вне карточки.
- Детальная страница объявления с галереей, характеристиками, удобствами, картой, похожими объектами и кнопками «Поделиться».
- Раздел закладок с категориями, карточками и пагинацией.
- Новости: список материалов, поиск по заголовкам, query-параметр `filter`, пагинация, loader и обработка ошибки.
- Детальная страница новости с датой, изображением, полным текстом, breadcrumbs и блоком «Читайте также».
- Авторизация с валидацией логина и пароля, переключателем «Запомнить меня» и переходом в личный кабинет.
- Регистрация с валидацией логина, email и пароля, Google reCAPTCHA и модальным сообщением о подтверждении email.
- Страница контактов с данными из API, контактной формой, социальными сетями и модальным подтверждением отправки.
- Страница тарифов и размещения: бесплатное, платное и Premium-размещение, приоритет, оплата по счёту и картой.
- Личный кабинет: профиль, «Мои объявления», фильтры категорий и статусов, поднятие объявлений, добавление объявления и инструкция по оплате.
- Модальные сценарии покупки пакета поднятий, выставления счёта и выбора способа оплаты.
- Многошаговый интерфейс добавления объявления: адрес, описание, цена, комнаты и спальные места.
- Общие header/footer, динамическая навигация, выпадающее меню, breadcrumbs, переиспользуемые UI-компоненты и адаптивная стилизация.

##  Архитектура

Приложение построено вокруг `BrowserRouter` с общим layout для основных страниц. Глобальное состояние хранится в Redux Toolkit и разделено на слайсы:

- `flats`, `cottages`, `baths`, `cars` — данные объявлений и состояния загрузки;
- `news` — новости, поиск, загрузка и ошибки;
- `filter` — параметры фильтра, результаты, сортировка и вид карточек;
- `recommend` — рекомендованный режим фильтрации;
- `bookmarks` — состояние избранного;
- `modal` — открытие модальных окон и их содержимое.

Загрузка каталогов и новостей выполняется через типизированные `createAsyncThunk`. Общая логика фильтрации вынесена в `useFilter`, а разбиение данных на страницы — в `usePagination`. Для запросов простых справочных данных используется общий хук `useRequest`.

##  Основные пользовательские сценарии

### Поиск объекта

1. Пользователь выбирает параметры на главной странице.
2. После отправки открывается каталог квартир.
3. В каталоге можно изменить категорию, применить дополнительные фильтры и выбрать сортировку.
4. Результаты отображаются плиткой или списком, с пагинацией.
5. Из карточки можно открыть контакты владельца или перейти к подробностям объекта.

### Работа с новостями

1. Пользователь открывает раздел новостей.
2. Вводит поисковый запрос — он синхронизируется с параметром `filter` в URL.
3. Список фильтруется по заголовкам без учёта регистра.
4. Выбор материала открывает детальную страницу с полным текстом и кнопками публикации в соцсетях.

### Регистрация и личный кабинет

1. Пользователь заполняет регистрационную форму и проходит reCAPTCHA.
2. После отправки показывается модальное сообщение о подтверждении аккаунта.
3. Форма входа с валидными полями переводит пользователя в `/personal`.
4. В кабинете доступны профиль, объявления, фильтры статуса, продвижение и платёжные сценарии.

## 🚀 Локальный запуск

Требуется Node.js и npm.

```bash
npm install
npm start
```

Приложение откроется по адресу `http://localhost:3000`.

Сборка production-версии:

```bash
npm run build
```

Запуск тестового набора:

```bash
npm test
```

##  Переменные окружения

Переменные окружения для запуска проекта не используются. Данные приложения отдаются локальным Mirage JS-сервером из JSON-файлов в `src/server/data/`.

##  Локальный API

Mirage JS подключается при старте приложения и имитирует GET-endpoints:

```text
/api/navigation
/api/userAccountNav
/api/menu
/api/news
/api/flats
/api/cottages
/api/baths
/api/cars
/api/contacts
/api/sidebar
```

Каталожные данные и новости загружаются асинхронно с состояниями loading/error. Реального backend API для пользователей, объявлений, авторизации и платежей в проекте нет.

##  Границы реализованного интерфейса

Проект представляет завершённый frontend-интерфейс с локальными данными и mock API. Авторизация и регистрация не проверяют учетные данные на сервере, формы контактов и добавления объявления не отправляют данные во внешний backend, а закладки не сохраняются между перезагрузками. Некоторые разделы личного кабинета (`/manual`, `/raise`, `/edit-account`) и карта представлены интерфейсными сценариями/заглушками.
